# Interactive Resume App

This is a Streamlit app that displays Wesley Thompson's resume in an interactive way.

## Features
- Interactive widgets: Section selector, skill level filter, contact info toggle
- Skills table and proficiency chart
- Experience timeline chart
- Download full resume PDF

## Local Run
```bash
pip install -r requirements.txt
streamlit run resume_app.py
```

## Deployment to Streamlit Community Cloud
1. Create a new GitHub repository
2. Upload `resume_app.py`, `requirements.txt`, and `Wesley_Thompson_Resume_2026.pdf`
3. Go to [share.streamlit.io](https://share.streamlit.io)
4. Connect your GitHub account
5. Select the repository and main file path `resume_app.py`
6. Deploy!
